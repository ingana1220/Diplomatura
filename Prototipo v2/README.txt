Archivo principal:
`lanzamiento_precio.html`

Permite seleccionar una categoría existente y cargar los ml del nuevo producto. Devuelve:
- precio sugerido;
- rango orientativo;
- nivel de confianza;
- comparables utilizados;
- prompt completo para IA Generativa.
